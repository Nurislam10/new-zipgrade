# Zipgrade KZ — тест тексеру

[ZipGrade](https://www.zipgrade.com/) үлгісіндегі веб-қосымша: мұғалім жауап парақтарын басып шығарады, оқушылар дөңгелектерді бояйды, ал телефон камерасы парақты бірнеше секундта тексеріп, баға қояды.

Барлығы браузерде жұмыс істейді: сервер, тіркелу немесе интернет қажет емес (бір рет ашылғаннан кейін офлайн да жұмыс істейді). Деректер құрылғының өзінде (localStorage) сақталады.

## Мүмкіндіктер

- **Жауап парақтары**: 1–100 сұрақ, 4 (A–D) немесе 5 (A–E) жауап, 6 таңбалы оқушы ID, 4 нұсқаға дейін (A–D). A4-ке басып шығарылады; сыныптың әр оқушысына аты мен ID-і алдын ала басылған парақтарды да шығаруға болады.
- **Камерамен сканерлеу**: парақтың 4 бұрышындағы қара шаршылар мен бағдар жолағы арқылы парақ табылады, перспектива түзетіледі, парақ 90°/180° бұрылған болса да оқылады. Камера болмаса, суретті жүктеуге болады.
- **Жауап кілті**: батырмалармен, мәтінмен (`ABCDA…`) немесе толтырылған парақты сканерлеу арқылы енгізіледі. Бір сұраққа бірнеше дұрыс жауап және сұрақты бағаламау мүмкіндігі бар.
- **Нәтижелер**: ұпай, пайыз, 5 балдық баға (шкаласы бапталады), тапсырмаған оқушылар тізімі, парақты қолмен түзету.
- **Талдау**: бағалар бөлінісі, әр сұраққа дұрыс жауап үлесі және жауап таңдауларының статистикасы.
- **Сыныптар**: оқушыларды бір-бірлеп немесе тізіммен (Excel-ден көшіріп) қосу.
- **Экспорт**: нәтижелерді CSV (Excel) форматына шығару, барлық деректердің JSON сақтық көшірмесі.

## Іске қосу

Құрастыру (build) қажет емес — бұл статикалық сайт.

```bash
npx serve -l 8080 .
# немесе: python3 -m http.server 8080
```

Содан кейін `http://localhost:8080` ашыңыз.

> Телефон камерасы тек **HTTPS** арқылы (немесе `localhost`-та) жұмыс істейді. Ең оңай жолы — GitHub Pages: репозиторий баптауларында **Settings → Pages → Deploy from a branch** таңдап, түбірлік қалтаны көрсетіңіз.

## Қолдану

1. **Сыныптар** → сынып құрып, оқушыларды ID нөмірімен қосыңыз (міндетті емес).
2. **Тесттер** → жаңа тест құрып, жауап кілтін енгізіңіз.
3. **Парақтар** → жауап парақтарын A4-ке 100% масштабпен басып шығарыңыз.
4. Тест өткеннен кейін **📷 Сканерлеу** басып, камераны параққа бағыттаңыз. Нәтижені тексеріп, **Сақтау** басыңыз.
5. **Нәтижелер** және **Талдау** беттерін қараңыз, қажет болса CSV-ге жүктеп алыңыз.

| `js/app.js` | Маршрутизатор және барлық беттер |

## Тесттер

```bash
npm install          # playwright
npm test             # OMR: түрлі бұрыш, көлеңке, бұрылыс жағдайлары
node tests/ui.test.mjs   # толық сценарий: сынып → тест → кілт → сканерлеу → нәтиже
```
